# HS2 Euston MEP dashboards

Installation progress dashboards for MEP cable containment, read live from the
SYNCHRO 4D schedule in Bentley's cloud.

Open https://timecube.github.io/euston-mep-dashboards/ and sign in with your Bentley
account. You need to be a member of the Euston project in Bentley.

No project data is stored here. The pages load data in your browser, after you sign in,
straight from Bentley's iTwin Platform (read only).
