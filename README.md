# HS2 Euston MEP Installation Progress

Live cable duct installation progress, read from SYNCHRO 4D in Bentley's cloud.

Open https://timecube.github.io/euston-mep-dashboards/ and sign in with your Bentley
account. You need to be a member of the Bentley project that holds the SYNCHRO project
"4D MEP Test Revit Import". There is nothing to set up.

No project data is stored here. The page loads the data in your browser, after you sign
in, straight from Bentley's iTwin Platform (read only).
